Equipment Library
Bins, compactors and chutes. The WMP spreadsheet reads these directly — after saving, hit Refresh All in Excel. No publish needed. A brand-new item also needs the spreadsheet block extended one row (copy the last formula row down).
AI Spec-Sheet Import
Upload a manufacturer spec sheet (PDF) — dimensions, capacities and contact details are extracted for review. Nothing touches the library until you accept each item, and every value stays editable before it lands.
Plan-View Shape Editor
Every item gets geometry automatically from its profile (or an inferred one) scaled to its width/depth — this panel shows exactly what the layout tool and DXF will draw, and lets you override it. Paths are authored in a 0..1 unit box (front of the item = top). A pasted path always wins over the generated one; whatever the drawing's proportions, it is normalised to the row's real dimensions, so the artwork can never introduce a dimensional error.

Contractors & Collection Vehicles
Collection services and vehicle dimensions. Same deal — Save here, Refresh All in Excel. New contractor = extend the spreadsheet block one row.
Swept path library: tick In swept lib to make a vehicle available in the swept path tool (needs wheelbase + kerb-to-kerb or wall-to-wall radius; wall-to-wall wins if both). Grouping is automatic: a Council value makes it council-specific (shown first for residential projects in that LGA); otherwise a Company makes it a contractor vehicle (commercial projects); neither = industry standard. Swept scope = residential / commercial / both. Austroads design vehicles live here too — swept tick on, contractor-table tick off. Swept changes feed the tool directly, no publish needed.
